# Design System: Engineering Precision & Blueprint Craft

<!-- impeccable:design-schema 1 -->

## Visual World: Precision Engineering & Developer Console

The portfolio is designed as an authentic software developer's workstation: precision-crafted, high-contrast, structured, and information-dense without clutter. It uses a deep midnight navy base (`#070b14` / `#0c1322`), electric cobalt and cyan accents (`#2563eb`, `#3b82f6`, `#38bdf8`), and high-readability slate typography. Monospace is reserved exclusively for real technical artifacts: code snippets, CLI shells, schema definitions, git metadata, and tabular metrics.

## Color Palette

- Background: `#070b14` (Deep Midnight Dev Canvas)
- Secondary Surface: `#0c1322` (Engineering Panel Background)
- Tertiary Elevated: `#131d31` (Sub-cards, terminal headers)
- Primary Accent: `#2563eb` / `#3b82f6` (Cobalt Blue Core)
- Secondary Accent: `#38bdf8` (Cyan Telemetry & Highlights)
- Success / Live: `#10b981` (Online status, test passes)
- Border Subtle: `#1a263d`
- Border Active / Glow: `rgba(59, 130, 246, 0.35)`
- Foreground Primary: `#f1f5f9` (Slate 100)
- Foreground Secondary: `#94a3b8` (Slate 400)
- Foreground Muted: `#64748b` (Slate 500)

## Typography

- Font Sans: Geist Sans (`var(--font-geist-sans)`) for clear, human, high-legibility headings and body text.
- Font Mono: Geist Mono (`var(--font-geist-mono)`) for code blocks, terminal prompts, system metadata, tags, and timestamps.
- Hierarchy:
  - Display / Hero Heading: 3.5rem to 4.5rem, font-extrabold, tight tracking (-0.03em)
  - Section Headings: 2rem to 2.5rem, font-bold, tight tracking (-0.02em)
  - Subheadings / Card Titles: 1.125rem to 1.25rem, font-semibold
  - Body Text: 0.9375rem to 1.0625rem, leading-relaxed (1.6 - 1.7)
  - Code / Telemetry: 0.75rem to 0.875rem, font-mono

## Components & Interactive Modules

1. **Hero Workstation**: Interactive tabbed developer console with simulated live shell, typed profile spec, and official developer portrait HUD.
2. **Architecture Blueprint (Projects)**: Interactive multi-tab breakdown of the "Noted." application featuring interactive architectural diagram, database schema preview, and REST endpoints.
3. **Skill Matrix**: Dynamic filtering by domain (Backend, Frontend, QA/Testing, Systems) with real competency context rather than generic word clouds.
4. **Engineering Trajectory**: Integrated chronological path combining formal education (Bolyai 5-year Tech + BME VIK) with proven work ethic milestones.
5. **Developer Contact HUD**: Instant copy utilities, direct functional Web3Forms dispatch, and direct contact telemetry.
